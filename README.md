# 수도권 법정 부설주차장 산정 계산기
건축물의 <지역/용도/시설 규모>를 입력하면 관련 법령 및 지자체 조례에 따라
법정 부설주차장 설치대수를 산정하는 계산기입니다.

## 주요 기능
- 국가·서울·인천 지역별 기준 적용
- 건축물 용도 및 세부 시설별 기준 적용
- 시설면적·정원 등 입력에 따른 주차대수 자동 산정
- 적용 기준과 계산 과정 표시

## 적용 기준
- 「주차장법 시행령」 제6조 및 별표 1
- 서울특별시·인천광역시 주차장 조례
- 「건축법 시행령」 별표 1의 건축물 용도 분류

## 쟁점 및 한계
- 지자체별 조례에 따라 설치기준이 달라질 수 있음
- 경기도는 도 단위 공통 기준이 없어 시·군별 조례 검토 필요
- 공동주택·복합용도·증축·용도변경 등은 별도 기준 검토 필요
- 실제 인허가 시 최신 법령 및 해당 지자체 조례 확인 필요

## 개발
`HTML · CSS · JavaScript` 단일 파일로 구현하고
